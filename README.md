Hybrid Deep Learning Framework for Adaptive Malicious Link Detection and Web Threat Intelligence

This project helps detect malicious and harmful links using deep learning.

Malicious links can be used for phishing, fraud, and spreading malware. This project uses a hybrid deep learning framework to analyze links and identify whether they are safe or malicious.

The system aims to improve the detection of harmful links and help protect users from web-based cyber threats.


This repository contains the source code for the project.
